# Cascade 1.5.0

Status: source release and local image candidate. I have not published `miladsade96/cascade:1.5.0` to Docker Hub.

## Consumer protocol

This release completes the currently targeted Kafka 4.3.1 modern consumer surface. It adds heartbeat v1 and regex subscriptions, cooperative current/target assignment reconciliation, detailed consumer-group description, flexible multi-group and topic-ID offset reads, flexible topic-ID commits with member-epoch fencing, selected offset deletion, type-filtered listing, and flexible group deletion.

State format 3 persists regex subscriptions, client identity, assignment epochs, and current/target assignments. The decoder retains format-2 compatibility and supplies safe defaults during upgrade. Member-aware offset reads validate against the immutable acknowledged image, so they do not wait behind a tentative coordinator checkpoint.
